## Sobre mí

Soy estudiante de **Ingeniería de Sistemas en la Universidad Cooperativa de Colombia**, interesado en el desarrollo de software, la inteligencia artificial y la seguridad informática.

Me enfoco en construir aplicaciones, desarrollar soluciones backend y explorar tecnologías que permitan crear sistemas eficientes, escalables y seguros.

- 🔭 **Actualmente trabajando en:** [SportLeague](https://github.com/herrerapf), un proyecto de desarrollo de software orientado al ámbito deportivo.
- 🛡️ **Ciberseguridad:** profundizando en seguridad de aplicaciones web, fundamentos de seguridad informática y prácticas de desarrollo seguro.
- 🤖 **Inteligencia artificial:** explorando Machine Learning, análisis de datos y aplicaciones prácticas de IA.
- ⚙️ **Ingeniería de software:** trabajando con APIs REST, arquitectura backend, control de versiones, pruebas automatizadas y CI/CD.
- 🎓 **Formación académica:** Ingeniería de Sistemas — Universidad Cooperativa de Colombia.
- 📚 **Aprendizaje continuo:** Docker, DevSecOps, automatización y herramientas modernas de desarrollo.
- 🌌 **Intereses personales:** astronomía, exploración espacial y avances tecnológicos.
